# Certificate Images

This folder should contain the certificate design images that will be displayed in the certificate slider.

## Required Certificate Images

Place your certificate design JPG/PNG images in this folder with the following naming convention:

### Easter
- `Easter-01-eng.jpg`
- `Easter-02-eng.jpg` (if you have more variants)

### Birthday
- `Birthday-01-eng.jpg`
- `Birthday-02-eng.jpg`

### Christmas
- `Christmas-01-eng.jpg`
- `Christmas-02-eng.jpg`
- `Christmas-03-eng.jpg`

### Mother's Day
- `Mothers-day-01-eng.jpg`
- `Mothers-day-02-eng.jpg`

### Simple/General
- `Simple-01-eng.jpg`
- `Simple-02-eng.jpg`
- `Simple-03-eng.jpg`

### Valentine's Day
- `Valentine-01-eng.jpg`
- `Valentine-02-eng.jpg`

### Wedding
- `Wedding-01-eng.jpg`
- `Wedding-02-eng.jpg`
- `Wedding-03-eng.jpg`

## Image Specifications

- **Format**: JPG or PNG
- **Aspect Ratio**: 4:3 (recommended)
- **Recommended Size**: 800x600px or higher
- **File Size**: Keep under 500KB for optimal loading

## Adding New Certificates

To add a new certificate design:

1. Add the image file to this folder
2. Edit `certificate.php` and add a new `.certificate-blank` div in the slider
3. Follow the existing pattern for text placement and styling

## Text Overlay Positioning

The certificate template includes overlays for:
- Beneficiary name (positioned at ~35% from top)
- From/Giver name (positioned at ~50% from top)  
- Amount (positioned at ~80% from top)

Make sure your certificate designs have appropriate space for these text overlays.
